In this article, we will address the notions of **Basic SQL**, providing a quick introduction for beginners. SQL, or Structured Query Language, is a standard language for managing and manipulating relational databases. Whether you are a novice developer, a data analyst, or simply curious about the tech world, understanding the basics of SQL is a valuable and fundamental skill in today's IT landscape.

## What is SQL?

SQL is used to communicate with a database. According to ANSI (American National Standards Institute), it is the standard language for relational database management systems. SQL statements are used to perform tasks such as updating data, retrieving it, or modifying the database structure itself. A solid understanding of SQL is the first step for anyone who wants to work with data, a crucial skill for designing robust and high-performing [IT architectures](/en/solutions/it-architecture-design).

## Why is SQL important?

The importance of SQL lies in its versatility and its wide use in different professional roles. Here are the main reasons why it is a fundamental skill:

- **Data Retrieval**: It allows you to query and efficiently retrieve huge amounts of data, the basis for every [Business Intelligence and data analysis](/en/solutions/business-intelligence) activity.
- **Data Manipulation**: Allows you to insert, update, and delete records in a database.
- **Data Definition**: Used to create and modify database structures (such as tables and indexes).
- **Data Access Control**: Allows you to manage permissions and security for access to information.
- **Widely Used**: It is an essential skill for many technical roles, including backend developers, data scientists, database administrators, and business analysts.

## Key Concepts

To master basic SQL, you need to understand some fundamental concepts of relational database architecture:

- **Tables**: Data is stored in tables, which are structured collections of rows and columns.
- **Columns (Fields)**: Each column represents a specific attribute of a record (e.g., `name`, `email`).
- **Rows (Records)**: Each row represents a single entity or entry (e.g., a specific customer).
- **Primary Key**: A field (or a set of fields) that uniquely identifies each row in a table.
- **Foreign Key**: A field in a table that refers to the primary key of another table, creating a relationship and allowing [integration between different systems](/en/solutions/systems-integration).

To start practicing with SQL, you can:

- Follow tutorials and practical exercises.

## Basic SQL Commands

Here are some of the most common and indispensable SQL commands to start with:

### 1. `SELECT`
The `SELECT` statement is used to retrieve data from one or more tables in a database.

```sql
-- Select all columns from a table named 'employees'
SELECT * FROM employees

-- Select only specific columns
SELECT name, department FROM employees

-- Select data applying a filter with the WHERE clause
SELECT name, salary FROM employees WHERE department = 'Sales'
```

### 2. `INSERT INTO`
The `INSERT INTO` statement is used to add new records (rows) to a table.

```sql
-- Insert a new record for an employee
INSERT INTO employees (id, name, department, salary)
VALUES (101, 'Alice in Wonderland', 'Marketing', 70000)
```

### 3. `UPDATE`
The `UPDATE` statement is used to modify existing records in a table.

```sql
-- Update the salary of the employee named 'Alice in Wonderland'
UPDATE employees
SET salary = 75000
WHERE name = 'Alice in Wonderland'
```

### 4. `DELETE`
The `DELETE` statement is used to remove existing records from a table.

```sql
-- Delete a specific employee record using their id
DELETE FROM employees
WHERE id = 101 
```

This was just a brief overview. SQL is a powerful language with many more advanced features and capabilities to explore, but mastering these basic commands is the essential first step.
